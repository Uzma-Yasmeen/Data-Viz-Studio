What it does

Multi-format upload

CSV, JSON (standard and line-delimited) and XLSX, with dtype inference on load.

Automated EDA

Summary statistics, missing-value counts, dtype breakdown and a correlation heatmap, generated on upload.

Nine chart types

Line, bar, scatter, histogram, boxplot, pie, heatmap, pairplot and regression, in colours you pick.

Intelligent sampling

Datasets over 1,000 rows are sampled for plotting, so rendering stays responsive on large files.

Combined dashboard

Charts persist in session state across interactions and stack into a single dashboard view.

PDF reporting

Export every chart plus the statistical summary as one multi-page PDF report.
